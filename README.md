# PSUSphere

PSUSphere is a Django-based student organization management system. It allows users to manage colleges, academic programs, student organizations, students, and organization memberships through a web-based admin interface.

## Features

- Manage colleges
- Manage academic programs
- Manage student organizations
- Manage student information
- Manage organization memberships
- Django Admin interface
- Search and filter records in the admin panel
- Faker-generated initial data
- SQLite database support
